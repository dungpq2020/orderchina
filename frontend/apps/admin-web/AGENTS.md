# Responsive design

Mọi trang/component mới trong app này đều phải responsive — bố cục dùng được tốt trên cả mobile, tablet, desktop (Tailwind breakpoints `sm:`/`md:`/`lg:`...), không chỉ tối ưu cho màn hình rộng. Kiểm tra lại ở ít nhất 1 kích thước màn hình nhỏ (mobile) trước khi báo hoàn thành.
